# Rita Olisakwe — Portfolio

A responsive Technical Product Manager portfolio built with HTML, CSS, and JavaScript.

## Preview

Open `index.html` in a browser, or serve this folder with any static web server.

## GitHub Pages

Publish this repository, then select **Settings → Pages → Deploy from a branch → main → / (root)** and save.

No dependencies or build step are required. All local asset paths are relative, so the site supports GitHub Pages repository URLs.

Project case studies and product links are in `app.js`. Finex store links can be added to its `links` array when available.
